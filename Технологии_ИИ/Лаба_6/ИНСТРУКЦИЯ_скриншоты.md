# Как самому развернуть хранилище и снять скриншоты для отчёта (Windows)

Время: 30–60 минут. Команды вводятся в **командной строке (cmd)**, не в PowerShell.

## Шаг 1. PostgreSQL
1. Установить PostgreSQL с https://www.postgresql.org/download/windows/ со всеми компонентами по умолчанию (pgAdmin входит в комплект). **Запомнить пароль** пользователя `postgres`.
2. Окно **Stack Builder** в конце установки закрыть («Отмена»), оно не нужно.
3. Открыть **pgAdmin 4** → слева *Servers → PostgreSQL 1x* (ввести пароль) → правой кнопкой по *Databases* → *Create → Database…* → Database: `ai_project` → *Save*.

## Шаг 2. Python
1. Открыть cmd (Win+R → `cmd` → Enter) и проверить: `python --version`.
2. Если версии нет или открывается Microsoft Store, установить Python 3.12 с https://www.python.org/downloads/. **В первом окне установщика поставить галочку «Add python.exe to PATH»**. После установки открыть новое окно cmd.
3. Установить библиотеки:
   ```
   pip install pandas sqlalchemy psycopg2-binary matplotlib python-docx pyarrow
   ```

## Шаг 3. Скачать репозиторий
**Вариант А — через git** (если установлен Git for Windows, https://git-scm.com/download/win):
```
cd %USERPROFILE%\Documents
git clone -b claude/wonderful-noether-hvuv5x https://github.com/mfostorm/laby_4kurs.git
```
При первом обращении откроется окно входа в GitHub, нужно войти в свой аккаунт. Появится папка `Документы\laby_4kurs`.

**Вариант Б — без git:** на странице репозитория на GitHub выбрать ветку `claude/wonderful-noether-hvuv5x` → зелёная кнопка *Code* → *Download ZIP* → распаковать в «Документы».

## Шаг 4. Перейти в папку лабы
В проводнике открыть `laby_4kurs\Технологии_ИИ\Лаба_6`, кликнуть в адресную строку, набрать `cmd` и нажать Enter: откроется командная строка уже в этой папке. В ней задать пароль от PostgreSQL (действует до закрытия окна):
```
set DB_PASSWORD=ваш_пароль
```

## Шаг 5. Загрузка и скриншот EXPLAIN «до»
```
python load_dwh.py
```
Должно вывести 7 таблиц с пометкой `OK`. Индексов на этом этапе ещё нет.

В pgAdmin: правой кнопкой по базе `ai_project` → *Query Tool*. Вставить запрос и выполнить (F5):
```sql
EXPLAIN ANALYZE SELECT * FROM dwh.fact_observation WHERE tool_key = 57;
```
В результате будет `Seq Scan`. Снять скриншот области результата (Win+Shift+S) и сохранить как `img\05_explain_before.png`.

## Шаг 6. Проверки, индексы, замеры
```
python check_integrity.py
python optimize.py
python bench_load.py
```
`optimize.py` создаёт временную таблицу на 2 млн строк, это около минуты. Эти скрипты обновляют `results\*.json`, и отчёт будет построен по замерам на твоём компьютере.

## Шаг 7. Скриншоты в pgAdmin
Каждый запрос вставлять в Query Tool и выполнять (F5). Сохранять в папку `img\` **под этими именами** (старые файлы заменить).

**`05_explain_after.png`** — тот же запрос, теперь с индексом (`Index Scan using idx_obs_tool`):
```sql
EXPLAIN ANALYZE SELECT * FROM dwh.fact_observation WHERE tool_key = 57;
```

**`01_tables.png`** — таблицы хранилища:
```sql
SELECT c.relname AS table_name,
       pg_size_pretty(pg_total_relation_size(c.oid)) AS size,
       obj_description(c.oid) AS description
FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE n.nspname = 'dwh' AND c.relkind = 'r'
ORDER BY 1;
```

**`02_counts.png`** — количество записей:
```sql
SELECT 'dim_equipment' AS table_name, count(*) FROM dwh.dim_equipment
UNION ALL SELECT 'dim_quality_class', count(*) FROM dwh.dim_quality_class
UNION ALL SELECT 'dim_tool', count(*) FROM dwh.dim_tool
UNION ALL SELECT 'dim_failure_type', count(*) FROM dwh.dim_failure_type
UNION ALL SELECT 'dim_batch', count(*) FROM dwh.dim_batch
UNION ALL SELECT 'fact_observation', count(*) FROM dwh.fact_observation
UNION ALL SELECT 'fact_failure_event', count(*) FROM dwh.fact_failure_event;
```

**`03_orphans.png`** — висячие ссылки и NULL в ключах (во всех строках должно быть 0):
```sql
SELECT 'quality_class' AS check_name, count(*) AS bad_rows FROM dwh.fact_observation f
  LEFT JOIN dwh.dim_quality_class d ON f.class_key = d.class_key WHERE d.class_key IS NULL
UNION ALL SELECT 'tool', count(*) FROM dwh.fact_observation f
  LEFT JOIN dwh.dim_tool d ON f.tool_key = d.tool_key WHERE d.tool_key IS NULL
UNION ALL SELECT 'failure_type', count(*) FROM dwh.fact_observation f
  LEFT JOIN dwh.dim_failure_type d ON f.failure_type_key = d.failure_type_key WHERE d.failure_type_key IS NULL
UNION ALL SELECT 'null_keys', count(*) FROM dwh.fact_observation
  WHERE udi IS NULL OR class_key IS NULL OR tool_key IS NULL OR failure_type_key IS NULL;
```

**`04_stats.png`** — базовая статистика. Два запроса: выполнить по очереди и снять два скриншота, потом склеить их, например в Paint, в одну картинку. Или снять только второй, он нагляднее:
```sql
SELECT min(torque_nm) AS min_torque, max(torque_nm) AS max_torque,
       round(avg(torque_nm), 2) AS avg_torque, round(stddev(torque_nm), 2) AS stddev_torque,
       sum(machine_failure) AS failures
FROM dwh.fact_observation;
```
```sql
SELECT * FROM dwh.v_failure_rate_by_class;
```

> В pgAdmin не выполнять файл `sql\05_checks.sql` целиком: строки `\echo` — это команды консольного psql, pgAdmin выдаст на них ошибку. Запросы выше взяты из этого файла без них.

## Шаг 8. Пересобрать отчёт
В том же окне cmd:
```
python make_report.py
```
Скрипт сам склеит `05_explain_before.png` и `05_explain_after.png` в `05_explain.png` и соберёт `Отчёт_Лаба_6_Вариант_10.docx` с твоими скриншотами и замерами. PDF без LibreOffice не создастся, это нормально: открыть .docx в Word → *Файл → Сохранить как → PDF*. Титульный лист добавлять уже после пересборки.

## Если что-то пошло не так
| Ошибка | Что делать |
|---|---|
| `password authentication failed` | Неверный пароль в `set DB_PASSWORD=...` |
| `database "ai_project" does not exist` | Не создана база (шаг 1.3) |
| `connection refused` | Не запущен сервер: Win+R → `services.msc` → postgresql-x64-1x → Запустить |
| `No module named ...` | Не выполнен `pip install` (шаг 2.3) |
| `'python' не является внутренней или внешней командой` | Python установлен без галочки «Add to PATH»: переустановить с ней |
