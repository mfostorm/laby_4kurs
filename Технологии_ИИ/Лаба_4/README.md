## К защите: контрольные вопросы
1. **Стратегии заполнения пропусков:** температуры заполняются интерполяцией (плавный ряд), момент — как P/ω (мощность почти постоянна), износ — предыдущее значение + шаг класса, обороты — медиана по классу. Записи без метки отказа удаляются: эталон не восстанавливают. Выбор подтверждён экспериментом (табл. 4 отчёта).
2. **Выбросы:** найдены методом IQR с фиксированными границами из лабы 2 и не удаляются, а помечаются флагами. Это предотказные режимы; удаление или винзоризация уничтожили бы сигнал правил PWF и OSF.
3. **Новые признаки:** temp_diff_k, power_w, wear_torque, osf_limit — аргументы продукционных правил; power_margin, osf_margin — запас до порога для оценки риска в генетическом алгоритме; tool_cycle_id, cycle_pos — циклы инструмента.
4. **Как изменилось распределение:** на исходных данных — никак, значения совпадают поэлементно. На данных с дефектами распределения после очистки совпадают с исходными (рис. 3–4).
5. **Достаточно ли данных:** да — 10 000 записей при минимуме 500, без пропусков и дубликатов, разметка согласована.
