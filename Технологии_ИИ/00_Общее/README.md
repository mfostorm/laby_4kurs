## Мой вариант — № 10

**Предметная область:** промышленное оборудование и предиктивное обслуживание.

**Задача:** создать систему предсказания отказов оборудования для планирования профилактического обслуживания.

**Данные:** UCI: AI4I 2020 Predictive Maintenance Dataset; Kaggle: Machine Predictive Maintenance.

### Парадигмы ИИ

| Парадигма | Применение |
|---|---|
| Продукционные правила | Правила диагностики неисправностей по телеметрии датчиков |
| Фреймы | Фрейм единицы оборудования: тип, параметры, журнал отказов, регламент |
| Генетический алгоритм | Оптимизация расписания технического обслуживания |

### Ограничения

- Нейронные сети не применяются.
- Используется только свободное программное обеспечение.
- Минимальный объём датасета — 500 записей.

## Вводные данные по источникам

- Для каждого варианта предложены 3–4 открытых источника данных, все доступны бесплатно. Студент выбирает один или несколько датасетов в зависимости от задачи, остальные можно использовать как дополнительные или для сравнения.
- Лицензии CC0 и Public Domain не требуют дополнительного разрешения. Лицензия Research означает, что на сайте ресурса нужна бесплатная регистрация. Лицензия CC BY-NC допускает использование в учебных (некоммерческих) целях.
- Ссылки актуальны на момент составления документа. Если ресурс недоступен, датасет можно найти по названию на Kaggle, в UCI ML Repository или через Google Dataset Search.
- Источники носят рекомендательный характер: можно взять альтернативные открытые датасеты по согласованию с преподавателем. Обязательное условие — открытая лицензия, допускающая учебное использование (CC0, CC BY, Public Domain или Research). Минимальный объём датасета — 500 записей.

### Обозначения лицензий

| Обозначение | Значение |
|---|---|
| CC0 | Общественное достояние |
| CC BY | С указанием авторства |
| CC BY-SA | Авторство + Share Alike |
| CC BY-NC | Авторство, не коммерческое использование |
| Public Domain | Публичное достояние (США) |
| Open | Открытая лицензия |
| Free | Свободное использование |
